# Demo Depot Journal

Statische Webseite für ein virtuelles Depot mit 100.000 EUR Startkapital.

## Daten und Sicherheit

Ausschließlich ausgewählte Simulationsdaten. Keine Brokerverbindung, keine Zugangsdaten und keine echten Konto- oder Depotkennungen. Keine externen Skripte oder Tracker. Das Repository enthält nur die Webseite und diese Dokumentation.

Der enthaltene Startbericht ist eine historische Simulation und keine Live-Bewertung. Kursstand und Annahmen stehen auf der Webseite. Eine automatische Übernahme neuer Agentenberichte ist noch nicht angeschlossen.

## Vorschau

index.html im Browser öffnen. Die Seite benötigt weder Installation noch Build.

## Veröffentlichung

Das Repository wird zunächst privat angelegt. GitHub Pages wurde noch nicht aktiviert. Die Sichtbarkeit eines Repositorys ist nicht mit dem Zugriffsschutz einer späteren Website gleichzusetzen.
